# Getting Support

Thanks for using Sangeet.

## Before asking for help

1. Read the [README](README.md) and [Contributing Guide](CONTRIBUTING.md).
2. Check the [API reference](docs/API.md) and [architecture deep-dive](docs/ARCHITECTURE.md).
3. Search existing [issues](https://github.com/techprem324/sangeet/issues) for the same question or problem.
4. Reproduce the problem with the latest version when possible.

## Where to ask

- **Bug reports:** use the Bug Report issue template.
- **Feature ideas:** use the Feature Request issue template.
- **Contribution questions:** open an issue and explain what you are trying to change.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); do not post vulnerabilities publicly.

## Include useful details

Share your operating system, browser, Node.js and Python versions, the exact command or action, expected behaviour, actual behaviour, and relevant error messages.

Remove passwords, tokens, API keys, private URLs, personal data, and other secrets before sharing logs.

## Response expectations

This is a community project maintained on a best-effort basis. There is no guaranteed response or resolution time. Clear, reproducible reports help everyone.
